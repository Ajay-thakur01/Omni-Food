# 🍔 Responsive Food Delivery App

A modern and responsive **Food Delivery landing page** built using **HTML5 and CSS3**. The project focuses on creating a clean food-service website with responsive layouts, attractive sections, animations, city highlights, customer testimonials, pricing plans, and a contact form.

## 🚀 Features

* 📱 Fully responsive design for desktop, tablet, and mobile devices
* 🍕 Attractive food showcase gallery
* 🥗 Healthy food and food-delivery focused landing page
* ⚡ "How It Works" section with step-by-step ordering flow
* 🌎 City availability section
* ⭐ Customer testimonials
* 💳 Multiple subscription/pricing plans
* 📝 Contact / sign-up form
* 🎨 Modern UI with orange accent theme
* ✨ Scroll animations using AOS
* 🔤 Google Fonts integration using Lato
* 📐 Responsive layouts using CSS Grid system
* 🖼️ Local image assets for food, cities, customers, and app promotion

## 🛠️ Technologies Used

* **HTML5** — Website structure and semantic markup
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Project scripting and future interactivity
* **AOS (Animate On Scroll)** — Scroll-based animations
* **Ionicons** — Interface icons
* **Google Fonts** — Lato typography
* **CSS Grid System** — Responsive column-based layouts

## 🖥️ Website Sections

### 1. Hero Section

The landing section introduces the food delivery service with:

* Full-screen hero background
* Navigation menu
* Main call-to-action buttons
* Food delivery tagline

### 2. Features Section

Highlights the main benefits of the service:

* Food available throughout the year
* Quick food preparation
* Organic food
* Flexible ordering

### 3. Food Gallery

A responsive image gallery displays different food items using hover effects and image transitions.

### 4. How It Works

The ordering process is presented in three simple steps:

1. Choose a suitable plan
2. Pay for the plan and download the app
3. Start ordering food

### 5. Available Cities

The website showcases supported cities including:

* Lisbon
* London
* Berlin
* San Francisco

Each city includes information about customers, chefs, and social media.

### 6. Customer Testimonials

A dedicated testimonial section displays customer feedback along with customer images.

### 7. Pricing Plans

The project includes subscription plans with pricing information and plan features, allowing users to compare available options.

### 8. Contact / Sign-Up Section

A responsive form is included for users to provide their information and interact with the service.

### 9. Footer

The footer contains navigation links, social media links, and copyright information.

## 📱 Responsive Design

The project includes dedicated responsive CSS rules for different screen sizes.

| Device      | Responsive Support |
| ----------- | ------------------ |
| 🖥️ Desktop | ✅                  |
| 💻 Laptop   | ✅                  |
| 📱 Tablet   | ✅                  |
| 📱 Mobile   | ✅                  |

The responsive styles are primarily handled through:

```text
resources/css/queiries.css
```

The layout adapts navigation, columns, buttons, images, pricing cards, forms, and footer content for smaller screens.

## ▶️ How to Run

No installation or build process is required.

### 1. Download or Clone the Project

```bash
git clone <your-repository-url>
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd "Responsive Food Delivery app"
```

### 3. Run the Website

Simply open:

```text
index.html
```

in your preferred web browser.

For a better development experience, you can use **VS Code with the Live Server extension**.
